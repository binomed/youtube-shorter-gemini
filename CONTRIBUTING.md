# Contributing to youtube-shorter-gemini

## 🖋 Commits
Nous utilisons **Conventional Commits** :
- `feat:` : Nouvelle fonctionnalité
- `fix:` : Correction de bug
- `docs:` : Documentation
- `style:` : Formattage
- `refactor:` : Refactorisation
- `test:` : Ajout de tests
- `chore:` : Maintenance

## 🏗 Workflow
1. Utilisation de `/sprint-planning` pour le suivi.
2. `/create-story` pour détailler une tâche.
3. `/dev-story` pour l'implémentation.
4. `/code-review` avant de merger.
